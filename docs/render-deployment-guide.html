Chuẩn Bị Trước Khi Deploy

Trước khi tiến hành deploy, hãy đảm bảo rằng repository của bạn đã có đầy đủ các file cấu hình chuẩn:

Tệp tin Trạng thái Mục đích sử dụng
render.yaml Đã tạo sẵn Bản mô tả Blueprint giúp Render tự động nhận cấu hình vùng Singapore, Free Tier, Healthcheck.
package.json Đã cấu hình Chứa lệnh npm start, build:client và Node.js engine >=20.0.0.
server/config/deployConfig.js Đã tích hợp Tự động nhận diện môi trường Render qua process.env.RENDER hoặc DEPLOY_PLATFORM.
.gitignore Đã kiểm tra Loại bỏ node_modules/, dist/, file bí mật .env để bảo mật mã nguồn.
💡 Yêu cầu tài khoản:
Bạn chỉ cần 1 tài khoản GitHub và 1 tài khoản Render.com (đăng nhập nhanh bằng GitHub). Không bắt buộc phải thêm thẻ thanh toán (Credit/Debit Card) đối với gói Free Web Service.

Cách 1: Deploy 1-Click Bằng Blueprint (render.yaml)

Đây là cách nhanh nhất, chuẩn xác nhất và ít xảy ra lỗi cấu hình nhất. Render sẽ tự động đọc file render.yaml đã được viết sẵn trong dự án.

  1. Đẩy code lên GitHub Repository

    Đảm bảo nhánh chứa mã nguồn mới nhất (ví dụ nhánh main) đã được push lên GitHub của bạn.

  2. Mở Render Dashboard và chọn Blueprint

    Đăng nhập vào dashboard.render.com. Bấm vào nút New + (ở góc trên bên phải) và chọn Blueprint.

  3. Kết nối GitHub Repository

    Chọn repository Box-Head-Game từ danh sách repo của bạn. Nếu chưa thấy, bấm Configure account để cấp quyền truy cập repository cho Render.

  4. Kiểm tra thông số tự động điền

    Render sẽ quét file render.yaml và hiển thị thông tin cấu hình:

    Service Name: boxhead-multiplayer-game
Runtime: Node
Region: Singapore (Độ trễ thấp nhất cho người chơi tại Việt Nam & ĐNÁ)
Plan: Free (0.1 CPU, 512 MB RAM)
Health Check Path: /healthz
Build Command: npm ci --omit=dev
Start Command: npm start
  5. Bấm Apply và Chờ Hoàn Tất

    Bấm nút Apply. Render sẽ bắt đầu clone repo, chạy npm ci và khởi động server. Quá trình mất khoảng 1-2 phút. Khi log báo Live, game đã sẵn sàng!

    ✔ Đường dẫn game của bạn:
    Render sẽ cung cấp domain HTTPS miễn phí có dạng:
    https://boxhead-multiplayer-game.onrender.com

Cách 2: Deploy Thủ Công (Manual Web Service)

Nếu bạn không muốn sử dụng Blueprint mà muốn tự tay cấu hình từng thông số trên giao diện web:

  1. Tạo Web Service mới

    Tại Render Dashboard, bấm New + -> chọn Web Service -> chọn repository GitHub của bạn.

  2. Điền thông số cơ bản (Basic Settings)
    Name boxhead-game (hoặc tên tùy thích)
    Region Singapore (hoặc Oregon/Frankfurt)
    Branch main
    Runtime Node
    Build Command npm ci --omit=dev (hoặc npm install)
    Start Command npm start
    Instance Type Free ($0/tháng)
  3. Cấu hình Biến Môi Trường (Environment Variables)

    Kéo xuống phần Environment Variables, bấm Add Environment Variable để thêm các khóa sau:

    Key Value Giải thích
    NODE_ENV production Chạy Node tối ưu hiệu năng
    DEPLOY_PLATFORM render Kích hoạt preset Render (giới hạn 20 phòng, snapshot 25Hz)
    SIMULATION_HZ 50 Tần số vật lý trò chơi (50Hz = 20ms/tick)
    SNAPSHOT_HZ 25 Tần số broadcast Socket.IO (giảm 50% CPU và băng thông)
    MAX_ROOMS 20 Giới hạn tối đa 20 phòng tránh quá tải RAM 512MB
    CORS_ORIGIN * Cho phép mọi nguồn kết nối socket
  4. Cấu hình Health Check Path

    Kéo xuống mục Advanced -> tại Health Check Path, điền:

    /healthz

    Render sẽ gửi request kiểm tra định kỳ tới endpoint này để xác nhận server đang sống ổn định.

  5. Bấm Create Web Service

    Bấm nút Create Web Service ở dưới cùng để khởi chạy tiến trình build và deploy.

Cách 3: Mô Hình Hybrid (Cloudflare Pages + Render Backend)

🎯 Vì sao nên cân nhắc mô hình này?
Gói Render Free chỉ bao gồm 5 GB băng thông ra (outbound bandwidth) mỗi tháng. Mỗi lần người chơi tải game sẽ tải khoảng ~6.5 MB hình ảnh sprite và âm thanh WAV. Nếu có 800 lượt tải trang, Render có thể hết quota băng thông.
Bằng cách chuyển giao diện tĩnh sang Cloudflare Pages (Băng thông miễn phí không giới hạn), Render chỉ cần gánh các gói tin Socket.IO siêu nhẹ, giúp game chạy ổn định vô thời hạn!
Frontend (Client) Cloudflare Pages

Phục vụ file HTML, CSS, JS, Sprite, Audio WAV

  • Băng thông: Không giới hạn (Unlimited)
  • Tốc độ CDN toàn cầu siêu nhanh tại Việt Nam
  • Lệnh build: npm run build:client
  • Thư mục xuất: dist
Backend (Socket.IO) Render Free

Phục vụ Game Loop 50Hz & Đồng bộ phòng

  • Chế độ: DEPLOY_PLATFORM=split-backend
  • Tắt phục vụ static file để dồn 100% RAM cho game
  • Băng thông chỉ tốn cho gói tin JSON Socket

Các bước triển khai mô hình Hybrid:

  1. Deploy Backend trên Render

    Deploy Render như Cách 1 hoặc 2, thêm biến môi trường:

    DEPLOY_PLATFORM=split-backend
CORS_ORIGIN=https://ten-client-cua-ban.pages.dev
  2. Tạo Cloudflare Pages Project

    Vào Cloudflare Dashboard -> Workers & Pages -> Create application -> tab Pages -> Kết nối repo GitHub của bạn.

  3. Điền thông số Build trên Cloudflare Pages
    Build command npm run build:client
    Build output directory dist
    Environment Variable BACKEND_URL = https://ten-backend-tren-render.onrender.com
  4. Hoàn thành

    Cloudflare sẽ tự động build ra thư mục dist/ với file config.js trỏ thẳng về Backend Render của bạn.

Các Cơ Chế Tối Ưu Cho Render Free Tier Đã Tích Hợp

Dự án đã được lập trình sẵn các cơ chế bảo vệ và tối ưu đặc thù để game vận hành mượt mà trên môi trường Render Free:

1. Xử lý "Spin Down" (Ngủ đông sau 15 phút) & Cold Start (30-60s)

Gói Render Free sẽ đưa server vào trạng thái ngủ sau 15 phút không có người truy cập. Giao diện game ở [client/index.html] đã tích hợp sẵn Connection Status Banner: khi người chơi mở trang web, client sẽ hiển thị "⏳ Đang đánh thức máy chủ... (Lần đầu có thể mất 30–60s)" và tự động thử lại (retry) liên tục cho tới khi kết nối thành công mà không bắt người chơi phải F5 lại trang.

2. Sửa lỗi "Sao chép link phòng" trên Cloud

Trước đây khi chơi LAN, game tự lấy IP nội bộ của máy chủ (ví dụ http://192.168.1.x). Khi lên Render, container chạy sau reverse proxy với IP nội bộ dạng 10.x.x.x. Hàm DeployClient.resolveRoomInviteBaseUrl() đã được nâng cấp: khi phát hiện giao thức HTTPS hoặc domain internet, game luôn tạo link phòng chuẩn dạng https://ten-game.onrender.com/#room=xxxx, giúp bạn bè bấm vào là vào thẳng phòng.

3. Tách Snapshot HZ (25Hz) khỏi Simulation HZ (50Hz)

Render Free chỉ cấp 0.1 vCPU. Nếu phát 50 gói snapshot mỗi giây cho từng người chơi, CPU sẽ bị nghẽn dẫn đến lag. Server được tối ưu: vật lý di chuyển & né đạn vẫn tính toán chuẩn xác ở 50 Hz, nhưng chỉ gửi gói tin đồng bộ ở 25 Hz. Phía Client, bộ nội suy Interpolator.js tự động điều chỉnh buffer lên 60ms, giúp nhân vật và zombie di chuyển mượt như nhung mà tiết kiệm 50% CPU & mạng.

4. Giới hạn MAX_ROOMS = 20 & Graceful Shutdown

Để tránh tràn bộ nhớ RAM 512MB khi có nhiều người tạo phòng rác, server áp đặt ngưỡng tối đa 20 phòng cùng lúc. Khi Render cập nhật bản build mới hoặc restart container, tín hiệu SIGTERM sẽ kích hoạt dọn dẹp các timer phòng game sạch sẽ trước khi thoát.

Kiểm Tra & Khắc Phục Sự Cố (Troubleshooting)

Các bước kiểm tra sức khỏe sau khi Deploy

  • Kiểm tra Health Check: Truy cập trình duyệt vào https://ten-game.onrender.com/healthz.
    Kết quả mong đợi: {"status":"ok","platform":"render","mode":"monolith","uptimeSec":...,"rooms":0}
  • Kiểm tra API Info: Truy cập https://ten-game.onrender.com/api/info.
    Kết quả mong đợi: {"lanIp":null,"port":10000,"platform":"render","mode":"monolith","exposeLanIp":false}
  • Kiểm tra Runtime Config: Truy cập https://ten-game.onrender.com/config.js.
    Kết quả mong đợi: trả về mã Javascript gán biến window.BOXHEAD_DEPLOY_CONFIG.

Bảng xử lý các lỗi thường gặp

Hiện tượng / Lỗi Nguyên nhân Cách khắc phục
Lần đầu mở web tải rất lâu (gần 1 phút) Server Render Free tự ngủ sau 15 phút không có khách. Đây là cơ chế bình thường của gói Free. Xem thanh thông báo ở sảnh để biết server đang thức dậy. Một khi đã thức, game chạy tức thì.
Deploy báo lỗi build hoặc start thất bại Thiếu dependencies hoặc sai câu lệnh start. Vào tab Logs của Render kiểm tra. Đảm bảo Build Command là npm ci --omit=dev và Start Command là npm start.
Bấm "Copy Link Phòng" bạn bè không vào được Dùng phiên bản cũ bị dính IP mạng nội bộ 10.x.x.x. Cập nhật nhánh mới nhất có client/js/deployClient.js. Link copy trên trình duyệt sẽ luôn là domain Render của bạn.
Mất kết nối giữa trận đấu Mạng chập chờn hoặc hết quota băng thông 5 GB. Kiểm tra tab Metrics trên Render xem lượng bandwidth đã dùng. Nếu sắp hết 5 GB, hãy chuyển sang mô hình Cách 3 (Hybrid với Cloudflare Pages).
